# AWS Infrastructure as Code with Terraform

## Overview

This project explores the deployment and management of cloud infrastructure on Amazon Web Services (AWS) using Terraform.

The objective is to apply Infrastructure as Code (IaC) principles to create reproducible infrastructure and organize resources across development and production environments.

## Technologies

- **Cloud Provider:** Amazon Web Services (AWS)
- **Infrastructure as Code:** Terraform
- **Storage and Static Hosting:** Amazon S3
- **DNS Management:** Amazon Route 53
- **Version Control:** Git and GitHub

## Key Concepts

- Infrastructure provisioning with Terraform
- Separation of development and production environments
- Terraform state management
- S3 website hosting
- DNS configuration and domain management
- Infrastructure versioning and reproducibility

## Architecture

The planned architecture uses Terraform to manage AWS resources, Amazon S3 for website hosting and storage, and Route 53 for DNS configuration.

## Learning Objectives

- Understand cloud infrastructure fundamentals
- Automate infrastructure deployment
- Organize infrastructure configuration using reusable code
- Apply version-control practices to infrastructure projects
